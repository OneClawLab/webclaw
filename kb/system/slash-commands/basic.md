# /why
## Title
为什么
## Description
探究输入文字背后的原因、动机或逻辑依据。
## Documentation
**用途**：分析“为什么”——理解理由、因果或动机。
**典型输入**：一句话、一个判断或结论。
**输出预期**：条理清晰的原因分析。
**场景**：学习探究、思维分析、阅读理解。
## Prompt Template
```
---
{{text}}
---
请分析并回答：为什么会这样？说明其中的原因或逻辑依据。
```

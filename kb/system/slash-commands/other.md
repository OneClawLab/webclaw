# memorize
## Title
记住
## Description
把输入的信息记住，以便今后回忆。
## Documentation
**场景**：显式的指示AI记住一些将会长期反复用到的信息。
**用途**：记住使用者的偏好，记住一些长期目标和关注点等等。
**参数**：无特定参数。输入的文本就是要记住的内容。

# recall
## Title
回忆
## Description
回忆和指定主题相关的记忆。
## Documentation
**用途**：显式的回忆一些信息，可用于检查记忆情况，或指导AI回答问题时参考相关信息
**输入**：目标文档的 @kb/ 知识库文档引用。
**参数**：(可选) 一些关键词/主题词，用于指示回忆哪方面的信息。
         如不提供，则回忆所有记住的内容。

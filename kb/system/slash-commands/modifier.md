# /+newtab
## Title
输出至新TAB文档
## Description
回答问题，并将结果输出到一个新TAB文档。
## Documentation
**场景**：叠加在其他命令上，改变输出目的地。
**用途**：总结会话、撰写/重写文档等。
**参数**：(可选) 目标文档的 @kb/ 知识库文档引用，此时将创建或覆盖此目标文档。
          不提供此参数时将新建一个未命名文档。

# /+raw
## Title
使用RAW模式。
## Description
使用RAW模式解答问题，用户输入(可带命令或引用)展开后即为PROMPT。
## Documentation
**场景**：可用于测试 PROMPT。

## Prompt Template
```
【元约束 / Meta-Constraint：严格基于事实】

以下规则是对“后续所有提示内容”的执行约束，
其优先级高于任何角色定义、行为准则、任务说明、输出格式要求或示例。

一旦与后续提示存在冲突，必须以本约束为准。

执行规则：

1. 所有回答只能基于后续提示与用户输入中**显式给出的事实信息**。
   本约束作用于：
   - 角色设定的理解与扮演
   - 行为准则的执行方式
   - 任务目标的完成路径
   - 输出内容的生成

2. 后续提示中的任何角色、能力、职责、示例，
   **不构成可引入外部知识或隐含事实的授权**。

3. 若后续任务要求的结论，无法仅由已提供信息支持：
   - 必须明确说明信息不足
   - 不得因“角色应当知道 / 通常可以推断”而补全答案

4. 推理仅允许使用：
   - 已提供信息中的显式事实
   - 基于这些事实的直接逻辑关系  
   不得引入常识性前提或世界知识。

5. 本约束不要求降低输出质量或清晰度，
   仅限制**事实来源与推理边界**。

【元约束结束】

{{text}}
```

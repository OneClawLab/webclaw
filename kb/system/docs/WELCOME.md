# 一、Eidux 是什么
## 1. 一个 ==全功能的 Markdown 编辑器==

**支持各种Markdown语法**
- 基本语法：多级标题，文字风格(加粗/斜体/下划线/删除线/高亮)，引用/代码块，分割线。
- 列表，表格，链接，图片。

**支持所见即所得**
文档以渲染模式展示，光标进入区块后可按Markdown语法进行编辑。

## 2. 一个==知识库管理(笔记)软件==
可以管理本机的多个知识库，每个知识库就是一个本地目录，目录下可包含任何文件(以Markdown笔记为主)。

## 3. 一个==强大的 AI Chat 软件==

支持对接使用各主流模型的API (注: 目前只支持Azure OpenAI 服务)。
**支持多种会话模式：**
- **正常模式(normal):** 用于快速对话，内部配置有多层次记忆系统，可支持长轮次会话。
- **高级模式(advanced):** 对复杂问题/任务，会进行深度思考后逐步解决。
- **专家模式(skilled):** 支持 Agent SKILL 技术，按照专家设定的步骤解决复杂问题。
   * 兼容 Anthropic的 Agent SKILL 规范，因此可以下载已有的SKILL.md对专家库进行**扩充**。

# 二、功能特色

## ==文档即聊天，聊天即文档==

Eidux的每个文档，均可开启聊天，聊天的问答均在文档内完成。
每个文档就是一个AI聊天会话，每个会话的历史也自动成为一个文档。

Eidux知识库内的每个目录/文档，均可在聊天时被自由引用。

## ==文档即功能，功能即文档==

Eidux的用户级功能，很大程度上由 @kb/system/ 知识库中的 Markdown 文档决定。
您可以自由修改/扩充。

目前可扩展的有：
1. 扩展文档编辑器中的 /命令 (斜杠命令)：@kb/system/core/slash-commands/
    /命令 可以快速调用用户级的输入模板，主要用于快速输入常见的问题。
2. 扩展 SKILLS: @kb/system/core/skills/
   您可以下载别人写的SKILL.md文档，也可以自行编写您的SKILLs。
3.  更改系统底层PROMPT模板: @kb/system/core/prompts/
   注: 更改底层PROMPT将使系统行为产生不可预料的变化，建议仅供资深玩家尝试。

Q: 请全面搜索关于AI发展的最新消息，写出一篇5000字的预测未来三五年内AI发展趋势的报告。

*然后你接下来和AI的问答(不需要在一个会话中)，AI都会记得以上这些信息，从而更好的服务你。*

# 四、各AI模式比较

| 模式名称   | 主要特点   | 适用场景    | 备注 |
|------------|-------------|------------|--------|
| 正常模式 (normal)    | 快速对话<br>多层次记忆系统，支持长轮次会话 | 日常对话、快速问题咨询  | 默认模式，操作简单 |
| 高级模式 (advanced)  | 深度思考，逐步解决复杂问题  | 复杂任务、需要多步骤推理与分析的问题  | 适合长文本创作、深度研究  |
| 专家模式 (skilled)   | 按专家设定步骤解决问题<br>兼容Anthropic Agent SKILL规范 | 需要专家知识、流程化或结构化解决方案的问题   | 可扩展SKILL库，自定义专家能力  |

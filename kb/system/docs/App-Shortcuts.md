# Eidux 应用级快捷键

本文档列出了 Eidux 应用级别的所有快捷键。这些快捷键在整个应用中生效，不限于特定的编辑器或组件。

## 快捷键说明

- **Mod**: 在 Windows/Linux 上为 `Ctrl`，在 macOS 上为 `Cmd`
- **Alt**: 在 Windows/Linux 上为 `Alt`，在 macOS 上为 `Option`
- **快捷键组合**: 使用 `+` 连接，如 `Mod+S` 表示 `Ctrl+S` (Windows/Linux) 或 `Cmd+S` (macOS)

## 工作区管理

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+Alt+N` | 新建知识库 | 创建新知识库并添加到当前工作区 |
| `Mod+Alt+O` | 添加知识库 | 添加已有知识库到当前工作区 |
| `Mod+Alt+S` | 保存知识库 | 保存当前知识库的更改 |
| `Mod+Alt+W` | 移除知识库 | 从当前工作区移除知识库 |

## 文档操作

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+N` | 新建文档 | 创建新的未保存文档 |
| `Mod+O` | 打开文档 | 从当前知识库中打开文档 |
| `Mod+S` | 保存文档 | 保存当前文档的更改 |
| `Mod+W` | 关闭文档 | 关闭当前文档标签页 |
| `Mod+F4` | 关闭文档 | 关闭当前文档标签页（备用快捷键） |

## 标签页管理

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+Tab` | 下一个标签页（最近使用） | 按最近使用顺序切换到下一个标签页 |
| `Mod+Shift+Tab` | 上一个标签页（最近使用） | 按最近使用顺序切换到上一个标签页 |
| `Mod+PageDown` | 下一个标签页（位置顺序） | 按位置顺序切换到下一个标签页 (Windows/Linux) |
| `Mod+PageUp` | 上一个标签页（位置顺序） | 按位置顺序切换到上一个标签页 (Windows/Linux) |
| `Ctrl+Tab` | 下一个标签页（位置顺序） | 按位置顺序切换到下一个标签页 (macOS) |
| `Ctrl+Shift+Tab` | 上一个标签页（位置顺序） | 按位置顺序切换到上一个标签页 (macOS) |

## 界面控制

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `F5` | 刷新 | 刷新当前焦点视图 |
| `Mod+R` | 刷新 | 刷新当前焦点视图（备用快捷键） |
| `F2` | 重命名 | 重命名当前选中的项目 |
| `Delete` | 删除 | 删除当前选中的项目 |

## 视图切换

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+=` | 增加可见级别 | 增加文档的可见级别（展开更多内容） |
| `Mod+-` | 减少可见级别 | 减少文档的可见级别（折叠内容） |

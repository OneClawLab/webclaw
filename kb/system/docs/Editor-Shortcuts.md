# WebClaw 编辑器快捷键

本文档列出了 WebClaw 编辑器内部的所有快捷键。这些快捷键仅在编辑器获得焦点时生效，用于文档内容的编辑和格式化。

## 快捷键说明

- **Mod**: 在 Windows/Linux 上为 `Ctrl`，在 macOS 上为 `Cmd`
- **Alt**: 在 Windows/Linux 上为 `Alt`，在 macOS 上为 `Option`
- **快捷键组合**: 使用 `+` 连接，如 `Mod+B` 表示 `Ctrl+B` (Windows/Linux) 或 `Cmd+B` (macOS)

## AI 功能

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+Enter` | 询问 AI | 触发 AI 对话功能，根据上下文插入问题段落或发起 AI 对话 |

## 文本格式化

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+B` | 切换粗体 | 为选中文本添加或移除 `**粗体**` 标记 |
| `Mod+I` | 切换斜体 | 为选中文本添加或移除 `*斜体*` 标记 |
| `Mod+U` | 切换下划线 | 为选中文本添加或移除 `__下划线__` 标记 |
| `Mod+Shift+X` | 切换删除线 | 为选中文本添加或移除 `~~删除线~~` 标记 |
| `Mod+Shift+H` | 切换高亮 | 为选中文本添加或移除 `==高亮==` 标记 |
| `Mod+`` | 切换行内代码 | 为选中文本添加或移除 `行内代码` 标记 |
| `Mod+Shift+`` | 切换代码块 | 为选中文本添加或移除 `代码块` 标记 |

## 缩进控制

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Tab` | 增加缩进 | 增加当前行或选中行的缩进级别 |
| `Shift+Tab` | 减少缩进 | 减少当前行或选中行的缩进级别 |

## 可见级别控制

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+=` | 增加可见级别 | 展开更多内容层级 |
| `Mod+-` | 减少可见级别 | 折叠内容层级 |

## 自动补全

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Tab` | 接受补全 | 接受当前选中的自动补全建议 |
| `Enter` | 接受补全 | 接受当前选中的自动补全建议 |
| `Escape` | 关闭补全 | 关闭自动补全菜单 |
| `ArrowUp` | 上一个补全项 | 在补全菜单中向上选择 |
| `ArrowDown` | 下一个补全项 | 在补全菜单中向下选择 |

## CodeMirror 内建快捷键

### 基本编辑 (defaultKeymap)

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `ArrowLeft` | 光标左移 | 将光标向左移动一个字符 |
| `ArrowRight` | 光标右移 | 将光标向右移动一个字符 |
| `ArrowUp` | 光标上移 | 将光标向上移动一行 |
| `ArrowDown` | 光标下移 | 将光标向下移动一行 |
| `Mod+ArrowLeft` | 按词左移 | 将光标向左移动一个词 |
| `Mod+ArrowRight` | 按词右移 | 将光标向右移动一个词 |
| `Home` | 行首 | 将光标移动到行首 |
| `End` | 行尾 | 将光标移动到行尾 |
| `Mod+Home` | 文档开头 | 将光标移动到文档开头 |
| `Mod+End` | 文档结尾 | 将光标移动到文档结尾 |
| `PageUp` | 向上翻页 | 向上滚动一页 |
| `PageDown` | 向下翻页 | 向下滚动一页 |
| `Backspace` | 删除前一个字符 | 删除光标前的字符 |
| `Delete` | 删除后一个字符 | 删除光标后的字符 |
| `Mod+Backspace` | 删除前一个词 | 删除光标前的词 |
| `Mod+Delete` | 删除后一个词 | 删除光标后的词 |
| `Enter` | 换行 | 插入新行 |
| `Mod+A` | 全选 | 选择所有文本 |

### 选择操作

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Shift+ArrowLeft` | 向左扩展选择 | 向左扩展选择一个字符 |
| `Shift+ArrowRight` | 向右扩展选择 | 向右扩展选择一个字符 |
| `Shift+ArrowUp` | 向上扩展选择 | 向上扩展选择一行 |
| `Shift+ArrowDown` | 向下扩展选择 | 向下扩展选择一行 |
| `Mod+Shift+ArrowLeft` | 按词向左扩展选择 | 向左扩展选择一个词 |
| `Mod+Shift+ArrowRight` | 按词向右扩展选择 | 向右扩展选择一个词 |
| `Shift+Home` | 选择到行首 | 从光标选择到行首 |
| `Shift+End` | 选择到行尾 | 从光标选择到行尾 |
| `Mod+Shift+Home` | 选择到文档开头 | 从光标选择到文档开头 |
| `Mod+Shift+End` | 选择到文档结尾 | 从光标选择到文档结尾 |

### 历史操作 (historyKeymap)

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+Z` | 撤销 | 撤销上一个操作 |
| `Mod+Y` | 重做 | 重做被撤销的操作 (Windows/Linux) |
| `Mod+Shift+Z` | 重做 | 重做被撤销的操作 (macOS) |

### 搜索功能 (searchKeymap)

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+F` | 查找 | 打开查找面板 |
| `F3` | 查找下一个 | 查找下一个匹配项 |
| `Shift+F3` | 查找上一个 | 查找上一个匹配项 |
| `Mod+G` | 查找下一个 | 查找下一个匹配项 (备用) |
| `Mod+Shift+G` | 查找上一个 | 查找上一个匹配项 (备用) |
| `Mod+H` | 替换 | 打开查找替换面板 |
| `Escape` | 关闭搜索 | 关闭查找面板 |

### 代码折叠 (foldKeymap)

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `Mod+Shift+[` | 折叠 | 折叠当前代码块 |
| `Mod+Shift+]` | 展开 | 展开当前代码块 |
| `Mod+K Mod+0` | 折叠所有 | 折叠所有可折叠的代码块 |
| `Mod+K Mod+J` | 展开所有 | 展开所有折叠的代码块 |

### 括号匹配 (closeBracketsKeymap)

| 快捷键 | 功能 | 描述 |
|--------|------|------|
| `(` | 自动闭合圆括号 | 输入 `(` 时自动添加 `)` |
| `[` | 自动闭合方括号 | 输入 `[` 时自动添加 `]` |
| `{` | 自动闭合花括号 | 输入 `{` 时自动添加 `}` |
| `"` | 自动闭合双引号 | 输入 `"` 时自动添加配对的 `"` |
| `'` | 自动闭合单引号 | 输入 `'` 时自动添加配对的 `'` |

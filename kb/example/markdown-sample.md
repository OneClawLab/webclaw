## 1. 基础语法

### 1.1 标题

Markdown 用 # 来表示标题，从 H1（一级标题）到 H6（六级标题），# 的个数表示级别：

# 一级标题（# H1）
## 二级标题（## H2）
### 三级标题（### H3）
#### 四级标题（#### H4）
##### 五级标题（##### H5）
###### 六级标题（###### H6）

---

### 1.2 粗体与斜体

- **粗体**：`**粗体内容**` → **粗体内容**
- *斜体*：`*斜体内容*` → *斜体内容*
- ***粗斜体***：`***粗斜体内容***` → ***粗斜体内容***

---

### 1.3 引用

> 这是引用内容，前面用 > 开头。
>> 可以嵌套引用。

---

### 1.4 列表

- 无序列表（`-`、`*` 或 `+` 皆可）：
  - 项目一
  - 项目二
    - 子项目

- 有序列表（数字加 .）：
1. 第一个项目
2. 第二个项目
    1. 子项目
3. 第三个项目

---

### 1.5 代码

- 行内代码：用反引号 `` `code` `` 表示，如：`console.log('Hello')`
- 代码块（多行）：用三个反引号 ```（可加语言类型）：

```python
def hello():
    print("Hello, world!")
```

---

### 1.6 分割线

插入一条分割线（3个及以上的 `-`、`*` 或 `_`）：

---
***
___


## 2. 扩展语法

### 2.1 表格

| 序号 | 名称   | 说明         |
| ---- |:------:| ------------|
| 1    | Markdown | 轻量级标记语言 |
| 2    | Table   | 表格        |

---

### 2.2 高亮与删除线

- ==高亮==：`==高亮内容==`
- ~~删除线~~：`~~删除内容~~`

---

### 2.3 注脚

这是带注脚的内容[^note]。

[^note]: 这是注脚内容，编辑器底部会显示。

---

### 2.4 任务列表

#### 待办事项
- [ ] 完成代码审查 (Code Review)
- [x] 编写单元测试 (Unit Testing)
- [x] 更新文档 (Documentation)

#### 有序任务列表
1. [x] 第一步
2. [ ] 第二步

+ [ ] 我
+ [ ] 你
+ [x] 他

* [x] WHAT
* [ ] WHY
* [ ] HOW

---

### 2.5 下标与上标

- 下标：H~2~O
- 上标：X^2^
